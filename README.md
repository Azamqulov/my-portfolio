# my-portfolio

Zamonaviy va interaktiv shaxsiy portfolio veb-sayti.

## 🚀 Texnologiyalar
- **Framework:** Next.js (React)
- **Styling:** Tailwind CSS
- **Interaktivlik:** Canvas Particles, Framer Motion
- **Dizayn:** Dark / Light theme (next-themes)

## 🛠 O'rnatish va Ishga tushirish

```bash
# Bog'liqliklarni o'rnatish
npm install

# Dasturni ishlab chiqish rejimida ishga tushirish
npm run dev
```
